API and webhooksالواجهة البرمجية والويب هوكس

For developers connecting their own tools to the CRM.للمطورين الذين يربطون أدواتهم الخاصة بنظام CRM.

Authenticationالمصادقة

Create a key in Settings → Developers. Send it on every request. The key is shown once; store it like a password. A key acts as the member who created it, limited to the scopes you choose, and stops working if that member leaves the workspace. Keys keep working after a password change: revoke keys you no longer trust.

أنشئ مفتاحًا من الإعدادات ← المطورون، وأرسله مع كل طلب. يظهر المفتاح مرة واحدة فقط؛ احفظه مثل كلمة المرور. يعمل المفتاح باسم العضو الذي أنشأه ضمن الصلاحيات التي تختارها، ويتوقف إذا غادر ذلك العضو مساحة العمل. تظل المفاتيح تعمل بعد تغيير كلمة المرور: ألغِ المفاتيح التي لم تعد تثق بها.

curl https://YOUR-BACKEND/api/contacts \
  -H "Authorization: Bearer crm_xxxxxxxxxxxx_…"

Errors are JSON {"statusCode": 403, "message": "…"}. An invalid, expired or revoked key gets 401 api_keys.invalid; a missing scope gets 403; more than 600 requests a minute per key gets 429 with Retry-After.

الأخطاء بصيغة JSON ‏{"statusCode": 403, "message": "…"}. المفتاح غير الصالح أو المنتهي أو الملغى يحصل على 401 api_keys.invalid، والصلاحية الناقصة على 403، وأكثر من 600 طلب في الدقيقة للمفتاح الواحد على 429 مع Retry-After.

Scopesالصلاحيات

Each resource gets Read, Write (includes Read: create and update), Delete or Admin (everything). Resources: contacts, conversations, tickets, pipelines, bookings, campaigns, templates, audiences, reports. Members, roles, billing, keys, settings and channels are never reachable with a key.

لكل مورد: قراءة، أو كتابة (تشمل القراءة: الإنشاء والتعديل)، أو حذف، أو إدارة كاملة (كل شيء). الموارد: جهات الاتصال، المحادثات، التذاكر، المسارات، الحجوزات، الحملات، القوالب، الجماهير، التقارير. لا يمكن الوصول بالمفتاح إلى الأعضاء أو الأدوار أو الفوترة أو المفاتيح أو الإعدادات أو القنوات.

Webhooksالويب هوكس

Add an https endpoint in Settings → Developers and pick its events. Each event is a JSON POST. Answer with any 2xx within 10 seconds. Anything else (including redirects, which are not followed) is retried after 1 minute, 5 minutes, 30 minutes, 2 hours and 8 hours: 6 attempts in all. An endpoint failing for 72 hours is turned off. Deliveries are at least once: use X-Crm-Event-Id to ignore duplicates.

أضف نقطة https من الإعدادات ← المطورون واختر أحداثها. كل حدث طلب POST بصيغة JSON. أجب بأي رمز 2xx خلال 10 ثوانٍ. أي رد آخر (بما في ذلك إعادة التوجيه، التي لا تتم متابعتها) يُعاد إرساله بعد دقيقة، ثم 5 دقائق، ثم 30 دقيقة، ثم ساعتين، ثم 8 ساعات: 6 محاولات إجمالًا. تُوقف النقطة التي تفشل لمدة 72 ساعة. قد يصل الحدث أكثر من مرة: استخدم X-Crm-Event-Id لتجاهل التكرار.

Verifying signaturesالتحقق من التوقيع

Each request carries X-Crm-Signature: t=<unix seconds>,v1=<hex>, where v1 = HMAC-SHA256(secret, t + "." + rawBody). After you rotate the secret, the old one keeps signing for 24 hours, so the header carries two v1 values; accept if any matches. Reject a timestamp more than 300 seconds (5 minutes) away from your clock. Always use the raw body, before any JSON parsing.

يحمل كل طلب الترويسة X-Crm-Signature: t=<ثوانٍ يونكس>,v1=<hex> حيث v1 = HMAC-SHA256(secret, t + "." + rawBody). بعد تدوير السر، يستمر السر القديم في التوقيع لمدة 24 ساعة، فتحمل الترويسة قيمتي v1؛ اقبل الطلب إذا طابقت أي منهما. ارفض الطابع الزمني الذي يبعد أكثر من 300 ثانية (5 دقائق) عن ساعتك. استخدم دائمًا النص الخام قبل تحليله كـ JSON.

import { createHmac, timingSafeEqual } from "node:crypto";

// header = req.headers["x-crm-signature"], rawBody = the request body as a string
export function verify(secret, header, rawBody, nowSec = Math.floor(Date.now() / 1000)) {
  let t = null;
  const sigs = [];
  for (const part of (header ?? "").split(",")) {
    const [k, v] = part.split("=");
    if (k === "t") t = Number(v);
    if (k === "v1") sigs.push(v);
  }
  if (!t || Math.abs(nowSec - t) > 300) return false; // replay window
  const expected = createHmac("sha256", secret).update(`${t}.${rawBody}`).digest();
  return sigs.some((s) => {
    const got = Buffer.from(s, "hex");
    return got.length === expected.length && timingSafeEqual(got, expected);
  });
}

Other headers: X-Crm-Event, X-Crm-Event-Id, X-Crm-Delivery-Attempt, User-Agent: AramCRM-Webhooks/1. Endpoint URLs must be public https addresses (port 443 or 8443) and cannot be changed after creation.

ترويسات أخرى: X-Crm-Event، X-Crm-Event-Id، X-Crm-Delivery-Attempt، User-Agent: AramCRM-Webhooks/1. يجب أن تكون روابط النقاط عناوين https عامة (المنفذ 443 أو 8443) ولا يمكن تغييرها بعد الإنشاء.
